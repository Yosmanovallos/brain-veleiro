# Knowledge Decisions

This directory contains retrieval-oriented compilations of approved decisions.

It does not replace ADRs.

Each artifact should point to the canonical decision source.

Use it when Brain needs a concise reusable answer to:

```text
What did we decide?
Why?
When does it apply?
Has it been superseded?
```

## Naming

```text
<decision-topic>.md
```

Recommended fields include:

- source ADR/reference;
- decision summary;
- rationale;
- consequences;
- applicability;
- supersession state;
- last checked date.
