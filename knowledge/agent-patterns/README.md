# Agent Patterns

This directory contains reusable patterns for agentic systems.

Examples:

- bounded tool loops;
- planner/worker separation;
- verifier patterns;
- human approval gates;
- delegation/context isolation;
- stop-condition patterns;
- context routing.

A pattern should describe:

- objective/problem;
- expected behavior;
- constraints;
- failure cases;
- verification approach;
- applicability;
- sources/provenance.

These are reusable patterns, not concrete AgentDefinitions.
