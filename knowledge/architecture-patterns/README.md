# Architecture Patterns

This directory contains reusable architecture patterns and their tradeoffs.

Each pattern should explain:

- problem;
- context;
- pattern;
- applicability;
- tradeoffs;
- failure risks;
- when not to use it;
- sources/provenance;
- validity.

Examples:

```text
provider-adapter-boundary.md
idempotent-write-handler.md
bounded-context-retrieval.md
```

Do not use this directory for project-specific decisions that belong in ADRs.
