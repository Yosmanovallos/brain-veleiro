# Knowledge Concepts

This directory contains reusable explanations of important concepts.

Use it for:

- domain concepts;
- system concepts;
- protocol concepts;
- product concepts;
- stable terminology.

A concept artifact answers:

```text
What is this?
How should Brain understand it?
What related concepts matter?
```

Do not use this directory for:

- ADRs;
- failure reports;
- architecture-pattern guidance;
- raw source files.

## Naming

```text
<concept-name>.md
```

Example:

```text
context-pack.md
knowledge-provider.md
```

Every artifact must cite its source/provenance and include validity metadata.
